# デジタル庁デザインシステム コードスニペット（React Aria版）

[デジタル庁デザインシステム](https://design.digital.go.jp/) のコンポーネントを、React Aria Components と Tailwind CSS をベースに実装したサンプル集です。

## React Aria版の特長

- デジタル庁デザインシステムに沿ったコンポーネント実装
- React Aria Components をベースにしたアクセシブルな振る舞い
- Tailwind CSS によるスタイリングと拡張しやすい設計
- Storybook 上で状態や見た目を確認しやすい構成

## 実装方針

このリポジトリでは、アクセシビリティ上の複雑な振る舞いを React Aria Components に委ねつつ、デザインシステムに合わせた見た目を Tailwind CSS で実装しています。

すべてのコンポーネントを提供することは目的としておらず、未実装のコンポーネントについては React Aria や ARIA Authoring Practices Guide (APG) を参考に、プロジェクトに合わせて実装を拡張してください。
